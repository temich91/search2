# fsearch — Быстрый поиск текста в файлах

Высокопроизводительный CLI-инструмент для поиска текста среди содержимого файлов на Windows, написанный на Rust.

## Возможности

- **Параллельный поиск** с использованием всех ядер CPU (rayon)
- **Regex и литеральный поиск** 
- **Рекурсивный обход** директорий
- **Статистика** поиска: скорость, количество файлов, совпадений
- **Поддержка кодировок** — UTF-8, Windows-1251
- **Контекст** вокруг совпадений
- **Фильтры** по расширению, размеру файла
- **Вывод в файл**
- **Оптимизирован для Windows**

## Сборка

```bash
cargo build --release
```

## Использование

```bash
# Простой поиск
fsearch "текст" C:\Projects

# Regex поиск
fsearch -r "fn\s+\w+" C:\Projects\src

# Поиск только в .rs и .toml файлах
fsearch "error" C:\Projects -e rs,toml

# Показать 2 строки контекста
fsearch "TODO" . -C 2

# Только имена файлов
fsearch "fixme" . -f

# Подсчёт совпадений по файлам
fsearch "use " . -e rs -c

# Статистика + вывод в файл
fsearch "pattern" C:\ --stats -o results.txt

# Только русскоязычные .txt файлы
fsearch "ошибка" C:\Docs -e txt -s
```

## Аргументы

| Аргумент | Описание |
|---|---|
| `pattern` | Поисковый шаблон |
| `path` | Директория поиска (по умолч.: `.`) |
| `-r` | Использовать regex |
| `-s` | Учитывать регистр |
| `-e ext1,ext2` | Включить расширения |
| `-x ext1,ext2` | Исключить расширения |
| `-m MB` | Макс. размер файла (по умолч.: 100 МБ) |
| `-t N` | Число потоков |
| `-C N` | Строк контекста |
| `-c` | Только счётчики |
| `-f` | Только имена файлов |
| `-b` | Включая бинарные файлы |
| `--hidden` | Включая скрытые файлы |
| `-o file` | Вывод в файл |
| `--stats` | Статистика |
| `--max-matches N` | Макс. совпадений на файл |
